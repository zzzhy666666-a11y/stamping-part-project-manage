# 精密五金件项目排期管理系统

## 🚀 快速启动

### 方法一：双击批处理文件（推荐）
1. 双击 **`启动网站.bat`** 文件
2. 等待服务器启动（看到 "Running on http://127.0.0.1:8000"）
3. 浏览器自动打开或手动访问：**http://localhost:8000**

### 方法二：命令行启动
```bash
cd "e:\项目排期网页工具2"
python app.py
```
然后访问：**http://localhost:8000**

---

## ❌ 错误用法

**不要直接双击 `index.html` 文件！**

原因：
- Flask后端没有启动，API接口无法访问
- 浏览器安全策略阻止本地文件调用API
- 会导致页面显示"加载中"或功能异常

## 🔧 常见问题

### Q1: 页面一直显示"加载中"？
**A**: 确保Flask服务器正在运行，并且通过 `http://localhost:8000` 访问

### Q2: 添加项目失败？
**A**: 
1. 检查服务器是否正常运行
2. 按 F12 打开浏览器控制台查看错误信息
3. 确保 `projects.json` 文件格式正确

### Q3: 修改代码后不生效？
**A**: 
1. 停止服务器（Ctrl+C）
2. 重新启动服务器（`python app.py`）
3. 强制刷新浏览器（Ctrl+Shift+R）

### Q4: 编辑器显示很多语法错误？
**A**: 这是VSCode的误报，把HTML模板字符串当作JSX解析了。只要浏览器能正常运行，可以忽略这些报错。

### Q5: 网页加载偏慢？
**A**: 可能的原因和优化方案：

#### **原因分析：**
1. **Tailwind CSS CDN加载** - 每次都要从网络下载样式库
2. **数据量增加** - 项目和任务越来越多时，渲染时间会增加
3. **浏览器缓存** - 首次加载需要下载所有资源

#### **优化方案：**
1. ✅ **已优化** - 添加了Tailwind预配置，减少运行时编译延迟
2. 🔄 **清除浏览器缓存** - 按 Ctrl+Shift+Delete 清除缓存
3. 🚀 **使用本地服务器** - 确保通过 http://localhost:8000 访问，而非直接打开HTML文件
4. 📊 **定期清理旧项目** - 如果项目太多，可以删除已完成或过期的项目

#### **性能监控：**
- 按 F12 → Network 标签页，查看资源加载时间
- 按 F12 → Performance 标签页，录制性能分析报告
- 关注 DOMContentLoaded 和 Load 事件的时间

## 💡 使用技巧

1. **创建新项目**：点击"➕ 新建项目"按钮
2. **查看详情**：点击项目行的任意位置
3. **编辑数据**：直接点击文字/数字进行修改，自动保存
4. **折叠展开**：
   - 点击阶段标题 → 收起/展开整个阶段
   - 点击主任务头部 → 收起/展开子任务
5. **强制刷新**：按 Ctrl+Shift+R 清除缓存
